设备授权接口文档

安全接入设备身份，完成授权签发与校验。

01 / 04

设备采集 CPU、主板、磁盘、内存与 IP，作为设备身份核验的输入。

获取授权码

提交 CPU 标识与加密硬件信息，获取设备授权码。

POST/authorize
Content-Type: application/json

请求参数

参数类型必填说明
cpu_idstring必填CPU 唯一标识，需与加密信息一致
encrypted_infostring必填AES 加密后的硬件信息（Base64）
tenantstring可选默认铝水；元一填写 yuanyi

业务线隔离：不传 tenant 默认铝水；元一设备传 yuanyi。

授权校验流程

  1. 1
    白名单检查设备是否允许接入
  2. 2
    设备状态校验指纹与封禁状态
  3. 3
    频率限制执行限流与单设备日限
  4. 4
    授权签发通过后签发授权码

响应字段

参数类型说明
auth_codestring签发的授权码，设备应持久化保存
device_fingerprintstring硬件指纹：SHA256 前 16 位
hardware_changedboolean同 CPU 下是否出现新的硬件指纹
is_new_deviceboolean该指纹是否首次出现
tenantstring实际写入的业务线
POST/verify_auth_code下一节：校验授权码 →
在线调试 手动填写参数后才会发送真实请求
Try it 左侧改参数，右侧实时生成请求；发送后响应错开入场

校验授权码

加解密约定

密钥与服务端 .env 一致（AES_KEY / DES_KEY / DES_IV），本文不展示明文密钥。

上报硬件明文格式

plaintext
cpu_id|motherboard_id|disk_id|memory_id|ip_address

加密算法

用途算法说明
设备 → 服务端 AES-ECB + Base64 加密硬件明文；用 \0 填充到 16 字节倍数
服务端 → 设备 DES-CBC + Base64 生成授权码；填充到 8 字节倍数

授权码明文格式

auth payload
cpu_id|motherboard_id|disk_id|memory_id|YYYY-MM-DD HH:MM:SS

最后一段为签发时间。默认有效期 {{ auth_code_max_age_seconds }} 秒（{{ auth_code_hours }} 小时）；设为 0 表示不校验过期。

业务线 tenant

白名单、授权记录、设备指纹均按业务线隔离，不可混用。

编码名称设备侧要求
lvshui铝水可不传，服务端默认铝水，兼容现网
yuanyi元一请求体必须带 "tenant":"yuanyi"

常见错误

当前策略：IP 限流 {{ rate_ip }}/{{ rate_window }}s · CPU 限流 {{ rate_cpu }}/{{ rate_window }}s · 单设备日限 {{ daily_limit }} 次。

HTTPerror 示例含义
400缺少必要的参数未传 cpu_id 或 encrypted_info
400CPU不在白名单当前业务线未录入该 CPU
400设备已禁用 / 授权已过期白名单状态或到期时间不通过
400授权验证失败解密失败或密文损坏
400CPU_ID与加密信息不匹配明文 cpu_id 与密文内不一致
400无效的业务线 tenanttenant 不是 lvshui / yuanyi
403设备已被封禁该设备指纹被封禁
403今日授权次数已达上限超过单设备日限额（当前 {{ daily_limit }}）
429IP / CPU 请求过于频繁触发限流
500服务器内部错误服务端异常

本地测试脚本

在项目目录运行脚本，自动采集硬件并请求授权码；支持 --host、--port 覆盖服务地址。

request_auth.py
python request_auth.py
python request_auth.py --tenant yuanyi

调用示例

选择语言后复制示例；示例请求中的密文需替换为设备实际生成的内容。

获取授权码 · 铝水

bash
curl -X POST "http://127.0.0.1:{{ authorize_port }}/authorize" \
  -H "Content-Type: application/json" \
  -d '{"cpu_id":"BFEBFBFF000B0671","encrypted_info":"<AES密文>"}'
python
import requests
r = requests.post(
    "http://127.0.0.1:{{ authorize_port }}/authorize",
    json={"cpu_id": "BFEBFBFF000B0671", "encrypted_info": "<AES密文>"},
    timeout=10,
)
print(r.status_code, r.json())
powershell
$body = @{ cpu_id = "BFEBFBFF000B0671"; encrypted_info = "<AES密文>" } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:{{ authorize_port }}/authorize" `
  -ContentType "application/json" -Body $body
200 JSON
{
  "auth_code": "<DES+Base64>",
  "device_fingerprint": "a1b2c3d4e5f67890",
  "hardware_changed": false,
  "is_new_device": true,
  "tenant": "lvshui"
}

校验授权码

bash
curl -X POST "http://127.0.0.1:{{ authorize_port }}/verify_auth_code" \
  -H "Content-Type: application/json" \
  -d '{"auth_code":"<授权码>"}'
python
import requests
print(requests.post(
    "http://127.0.0.1:{{ authorize_port }}/verify_auth_code",
    json={"auth_code": "<授权码>"},
).json())
200 JSON
{
  "valid": true,
  "payload": {
    "cpu_id": "...",
    "motherboard_id": "...",
    "disk_id": "...",
    "memory_id": "...",
    "issued_at": "2026-11-02 15:00:00"
  }
}
